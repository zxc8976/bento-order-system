# お弁当注文システム

会社の研修期間に作った作品です。お弁当の注文システムで、権限分離・フロントエンドとバックエンド分離の構成です。アプリのコードは demo/ ディレクトリに入っています。

このプロジェクトでパスワードのハッシュ化や権限管理を学びました。

## 技術スタック

- バックエンド：Spring Boot 3.2.6 + MyBatis-Plus + Java 17
- フロントエンド：Vue
