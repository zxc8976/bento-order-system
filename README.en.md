# Bento Order System

A project from my company training period. A bento ordering system with separated permissions and a decoupled frontend/backend architecture. The app code lives in the demo/ subdirectory.

Through this project I learned password hashing and permission management.

## Tech Stack

- Backend: Spring Boot 3.2.6 + MyBatis-Plus + Java 17
- Frontend: Vue
